# Security Policy

Report vulnerabilities privately through GitHub when available:
https://github.com/MrSausainis/Jyson/security/advisories/new

Do not post secrets, tokens, personal data, exploit details, or an unpatched vulnerability in a public issue.

Use only the installer from the official Releases page. The installer is not code-signed yet; updates are verified with the release signature and GitHub's SHA-256 checksum before they install.
